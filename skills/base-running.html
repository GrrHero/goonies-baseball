Running

Base Running

Through! Cue word — say only this while they move.

Why it matters

Outs at first often happen because kids slow down on the bag. Run through first, listen for the coach, and learn when to round vs. stop.

How to

  1. On a ground ball to the infield: sprint hard — don't watch the ball.
  2. Run straight through first base; break down after the bag.
  3. Listen for coach: "Through!" vs. "Round!" vs. "Back!"
  4. On extras: touch the inside corner and pick up the next coach.

Common mistakes

Slowing down or stopping ON first base
Put tape/a cone 2 steps past first. "Break the tape." Race through every time.
Watching the ball instead of running
Drill with no fielders first — pure sprint on contact. Eyes on the base coach.
Rounding when they should run through (or vice versa)
Simple code words only. Practice both on purpose in the same station.

Coach station drill

Practice · 4–5 min Break the Tape

Setup: First base + a ribbon/tape held 2 steps past; or a coach with arms as the finish line.

How: Kids line up at home in groups of 3. On clap, sprint through first and break the tape. Jog back wide. Next group goes — continuous flow, ~15 seconds between groups.

10-minute at-home drill

Home · 10 min Mailbox First Base

Gear: A towel/base as first, chalk or tape finish line past it

How: From a pretend home plate, parent says "Hit!" Child sprints through first past the line. Mix in "Round!" toward second sometimes. Time 3 reps and try to beat the best.

Level up

🚀 Hit an imaginary ball, run through first, then quickly locate where the ball would be (point to it).
