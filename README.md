# THE GOONIES — 8U Baseball Skills

Public team site for **Cedar Park Youth League** coach-pitch baseball.

**Live:** https://grrhero.github.io/goonies-baseball/

For volunteer coaches (field reference) and parents (10-minute home practice). No player names.

## Pages

- `index.html` — skill cards
- `skills/*.html` — each fundamental
- `coaches.html` — 60-min practice, freeze signal, praise, safety
- `parents.html` — one-week home plan + encouragement tips
- `cheat-sheet.html` — printable cue words

## Data

Skill content lives in `data/skills.json`. Videos were verified with YouTube oEmbed.
