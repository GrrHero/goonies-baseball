Catching

Fly Balls & Pop-Ups

Umbrella Cue word — say only this while they move.

Why it matters

Pop-ups are scary at this age. Safety first: call it, get under it early, glove up like an umbrella. Start with balloons/soft balls before real baseballs.

How to

  1. Find the ball early; call "Mine!" loud (one person).
  2. Run to where it will land — get under it, don't drift late.
  3. Glove up above the head like an umbrella (fingers to the sky).
  4. Two hands; soft catch. If unsure, let it drop — no collisions.

Common mistakes

Running with the glove already stuck up (can't see / balance)
Run with glove ready at chest; raise umbrella only at the last moment.
Two kids converging without calling
Rule: loud "Mine!" wins. Practice calling on every toss at practice.
Backing up flat-footed under a ball over the head
Teach a drop-step turn; use balloons first so fear stays low.

Coach station drill

Practice · 5 min Umbrella Raindrops

Setup: Coach with soft balls/balloons; kids spaced in an arc (not clustered).

How: High soft tosses one at a time to a named player. Everyone else freezes. Rotate names quickly so wait time stays short. Emphasize call + umbrella.

10-minute at-home drill

Home · 10 min Rainstorm

Gear: Balloons or soft balls, open yard

How: Parent tosses gentle "rain." Child gets under and umbrella-catches. Count consecutive catches. Progress to tennis balls only when confident.

Level up

🚀 Catch 5 raindrops in a row, then take one step farther from the tosser.
